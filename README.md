# ⌨️ لوحة المفاتيح العربية — Arabic Keyboard for Android

لوحة مفاتيح عربية **متكاملة ومفتوحة المصدر** لأندرويد، مبنية بالكامل بدون أي مكتبات خارجية (Java خالص + Canvas)، بحجم أقل من 100 كيلوبايت.

![Arabic Keyboard](docs/preview-arabic-dark.png)

![English Keyboard](docs/preview-english-light.png)

---

## ✨ الميزات

| الميزة | التفاصيل |
|--------|----------|
| 🇸🇦 عربية كاملة | الترتيب القياسي (ض ص ث ق...) مع Shift للحركات والعلامات العربية |
| 🇬🇧 إنجليزية | QWERTY مع أحرف كبيرة تلقائية وبداية الجمل |
| 🔢 أرقام | صف أرقام اختياري (١٢٣ مع بدائل غربية) + صفحة أرقام ورموز كاملة |
| 😊 إيموجي | لوحة إيموجي متكاملة (~170) مع أعلام عربية |
| 🎨 مظاهر | تلقائي / نهاري / ليلي / أسود AMOLED |
| 🌈 ألوان تمييز | أزرق، فيروزي، بنفسجي، ذهبي، أحمر |
| 📏 حجم المفاتيح | صغير / متوسط / كبير |
| 👆 إيماءات | سحب على المسافة لتحريك المؤشر، بدائل بالضغط المطوّل، Caps Lock بضغطة مطوّلة |
| ⌨️ ذكاء كتابي | نقطة بضغطتين على المسافة، حرف كبير تلقائي، تسريع تلقائي للمسح |
| ⚙️ تحكم | صوت واهتزاز قابلان للتعطيل، Enter ذكي حسب التطبيق (بحث/إرسال/تم) |
| 🪶 خفيفة جداً | أقل من 100KB — بدون androidx ولا مكتبات خارجية |

## 📲 التثبيت

1. حمّل أحدث حزمة من [Releases](../../releases) أو من مجلد `dist` بعد البناء
2. ثبّت الملف على جهازك (فعّل «مصادر غير معروفة» عند الحاجة)
3. افتح التطبيق:
   - **الخطوة ١:** «تفعيل اللوحة في إعدادات النظام»
   - **الخطوة ٢:** «اختيارها كلوحة الإدخال الحالية»
4. افتح أي تطبيق وابدأ الكتابة 🎉

متوافق مع **أندرويد 5.0 (API 21)** حتى **أندرويد 14+ (API 34)**.

## 🛠️ البناء من المصدر

المشروع مبني بسلسلة أدوات خفيفة بدون Gradle:

```bash
# المتطلبات: JDK 17+ (javac)، Android SDK (platform-34 + build-tools 34)
# سينزّل السكربت R8 تلقائياً عند أول تشغيل
export ANDROID_SDK_ROOT=/path/to/android-sdk
bash scripts/build_apk.sh
# الناتج: dist/Arabic-Keyboard.apk
```

يعمل سير العمل التلقائي **GitHub Actions** (`.github/workflows/build.yml`) عند كل Push
وينتج حزمة APK موقّعة كـ Artifact جاهزة للتنزيل.

## 🗂️ بنية المشروع

```
├── AndroidManifest.xml          # تعريف خدمة IME والنشاط الرئيسي
├── res/
│   ├── layout/activity_main.xml # شاشة الإعداد والتخصيص
│   ├── values/                  # نصوص عربية، ألوان، أبعاد
│   └── xml/method.xml           # تسجيل طريقة الإدخال لدى النظام
├── src/com/zai/arabickeyboard/
│   ├── ImeService.java          # خدمة الإدخال (قلب اللوحة)
│   ├── KeyboardView.java        # رسم Canvas وتفاعل اللمس والإيماءات
│   ├── Layouts.java             # تخطيطات الحروف والأرقام والرموز والإيموجي
│   ├── Key.java / Row.java      # نموذج المفاتيح
│   ├── ThemeSet.java            # المظاهر وألوان التمييز
│   ├── Prefs.java               # حفظ الإعدادات
│   └── MainActivity.java        # شاشة التفعيل والإعدادات
├── scripts/
│   ├── build_apk.sh             # سلسلة البناء الكاملة (aapt2 → javac → d8 → توقيع)
│   ├── make_icons.py            # توليد أيقونات التطبيق
│   └── make_mockup.py           # توليد صور المعاينة أعلاه
└── docs/                        # صور المعاينة
```

## 🧩 كيف تعمل؟

- **الرسم:** كل شيء مرسوم يدوياً عبر `Canvas` — مفاتيح دائرية الحواف، أيقونات Shift والمسح والإدخال مرسومة بـ `Path`، معاينة ضغط منبثقة، وبدائل تظهر فوق المفتاح عند الضغط المطوّل.
- **الإدخال:** التفاعل مع الحقول عبر `InputConnection` (إدخال نص، حذف آمن للإيموجي، تنفيذ إجراءات الحقول)، وتحريك المؤشر عبر أحداث DPAD.
- **الوضع الأفقي:** تعطيل وضع الملء الشاشة المزعج تلقائياً.
